# Security policy

This is an early research prototype, not suitable for sensitive accounts or untrusted networks. Read [the security model and limitations](docs/SECURITY.md) before running it.

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature. Do not post secrets, proof-of-concept access tokens, or private screenshots in public issues. If private reporting is unavailable, do not disclose exploit details publicly; contact the repository owner through a verified private channel.

Private vulnerability reporting is enabled. No response-time guarantee is currently offered.
